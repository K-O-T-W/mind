产品定义 · 操作

      
    

    

      

        
结构

        

          
Enter
新建同级，直接输入

          
Tab
新建子项，直接输入

          
Shift+Tab
提升一级，到顶层就独立成簇

          
Ctrl+] / Ctrl+[
缩进 / 提升

          
Alt+↑↓
同级挪位

          
Delete
删除；子节点留在原地升一级

          
Space
折叠 / 展开

          
C
蓝图注释框：选中节点就框住它们；空地按 C 在鼠标处新建

        

      

      

        
画布

        

          
拖顶节点
整簇跟着走

          
拖子节点
只能换父级，不能单独摆

          
拖空白
框选节点；框住注释框或框过标题栏也会选中它

          
双击空白
在那儿新建一个顶节点

          
中键 / 右键拖
平移画布

          
Ctrl+滚轮
以指针为中心缩放

          
F
适应画布

          
Alt+点连线
剪断：子节点带着子树独立成簇（按住 Alt 连线亮红）

          
拖注释框
框带着根在框里的簇一起走；右下角拖角拉伸

          
注释框色点
换颜色；选中后按 Delete 删框（节点全留）；双击框体或 F2 改名

        

      

      

        
走位与编辑

        

          
↑↓
上一个 / 下一个

          
← / →
折叠回父 / 展开进子

          
Shift+点
加选 / 取消选中

          
F2 或双击
编辑文字

          
N
打开 / 收起备注

          
Ctrl+Z
撤销

        

      

      

        
审批 AI 的改动

        

          
悬停节点
左上角浮出 ✓✕，就地决定

          
点了 ✓ / ✕
画布直接呈现生效后的样子；拒绝的当它不存在

          
再点一次
退回未决

          
框选 / Shift 点
批量选中，底部出现接受 / 拒绝

          
Enter / X
接受 / 拒绝（有批量选择时作用于全部）

          
↑↓
在左侧列表里逐条跳（先跳还没决定的）

          
点面板条目
画布滑过去把节点停在正中间；点画布节点，面板也指回那条

          
修改块
几处改动是同一条理由时打包成一块：整块点头，或展开逐条看；折叠状态不会自己变

          
备注行
程序自己逐行比对，只显示变了的行；N 看生效后的备注，新增行垫绿

          
已决
决定过的沉到底部，收着；展开点 ↩ 退回重审；面板关掉再开，决定不丢

          
Ctrl+Enter
全部接受（只做决定，画布即全生效的样子；写入另按按钮）

          
Esc
先不决定，一个字都不写

        

      

      

        
文件

        

          
Ctrl+S
保存（有文件就原地写）

          
Ctrl+Shift+S
另存为

          
Alt+O
打开，放进新标签

          
Alt+N
新建标签

          
拖 .proposal 进来
打开一份待审批的提案

          
左下角「让 AI 改」
点一下摊开：写要改什么，Ctrl+Enter 连文件的绝对路径和 propose 用法一起复制走

          
Alt+A
打开那张卡片；复制完它自己收起，Ctrl+Z 或「↩ 放回」把原话拿回来

        

      

      

        
标签

        

          
双击标签
改名（磁盘上的文件一起改）

          
Alt+1…9
跳到第 n 个标签

          
Ctrl+Alt+←→
前后切换

          
Ctrl+F
搜索节点和备注

        

      

    

    
文件就是一份 Markdown：每个节点一行 - ，两空格一级，节点下面以 > 开头的行是它的备注。顶节点行尾的 <!--@x,y--> 是它摆在画布上的位置；蓝图注释框则是整行 <!--@comment:…-->，写在它框住的第一个簇上面，行尾列着框住了谁——AI 一读就知道归属。渲染时都看不见。一个标签就是一个文件。
